# Project Universoul - Single Page Website

This project continues on much of the same theme of the previous version, with this focused on a single-page format and an updated more modernized look. Exploring new features with an image carousel, incorporating branded merchandise. Streamlining the overall experience for the brand.

This work explores new dimensions of the brand strategy and vision from The Universoul Productions Dream Project. Bringing more interactivity and objective focus on the company’s main services in audio and recording along with new branding mockups for company merchandise.

With this project I wanted to focus on the main idea/subject that is central to the company. In this case – with it being audio, and anchoring that to the scene, which is global.

There was no budget for this project and it was completed on time, though it did experience an issue with one of the new features that was quickly resolved. Responsiveness was later incorporated in the mix.
